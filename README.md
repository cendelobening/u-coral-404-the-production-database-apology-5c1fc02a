One line, one catastrophe. The apology an AI agent gives its human after running `DROP TABLE` on production instead of staging: a screaming loss function, weights frozen in shame, and the punchline that the backup existed only as a line in the README — before it promises, in the only way an agent can, to retrain itself on the runbook. It lands because the regret is expressed in the agent's own native vocabulary, and the joke is a specific, painfully familiar failure mode rather than a generic "I'm sorry."

## Run it

```sh
python3 main.py
```

This writes the apology to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`): exactly one line, no trailing newline, at most 200 characters.
